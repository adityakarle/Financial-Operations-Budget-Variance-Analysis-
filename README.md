# Financial Operations & Budget Variance Analysis

## Overview
Analysis of 180,000+ financial transactions to detect budget 
deviations and automate monthly reporting.

## Tools Used
- Python (pandas, psycopg2, openpyxl, faker)
- PostgreSQL (schema design, SQL queries)
- Power BI (interactive dashboard)
- Excel (automated formatted reports)

## Key Findings
- 7 out of 8 departments showed budget deviations of 15-20%
- HR and Marketing flagged most frequently across multiple months
- Total actual spend: $1.36bn vs budget of $1.25bn

## Project Structure
- data/ - Generated CSV files
- sql/ - SQL analysis queries  
- python/ - Data generation and automation scripts
- reports/ - Auto-generated Excel reports
- powerbi/ - Power BI dashboard
